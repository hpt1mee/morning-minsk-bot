# Утренний Telegram-бот для Минска

Каждый день в 08:00 по Минску бот отправляет погоду, занятия с присланной фотографии и напоминание по нужному транспорту у остановки «Лейтенанта Кижеватова».

## Что подготовлено

- График: 08:00, часовой пояс `Europe/Minsk` (UTC+3).
- Команда `/start` сохраняет chat ID; `/now` немедленно присылает сводку для проверки.
- Расписание занятий для понедельника–четверга переписано с фотографии. Пятница, суббота и воскресенье отображаются как дни без занятий.
- Прогноз — официальный API Яндекс Погоды для координат Минска. Для него нужен отдельный ключ Яндекса.
- Для транспорта выводится заданное пользователем окно 08:35–08:47 для маршрутов 73, 59 и 172, плюс ссылка на режим транспорта Яндекс Карт. Точного публичного API прогнозов прибытия Яндекс Карт нет, поэтому бот не выдаёт предположения за live-данные.

## Развёртывание на Railway

1. Создайте новый GitHub-репозиторий и загрузите туда содержимое этой папки. **Не загружайте** `.env` и не вставляйте токен в код.
2. На [Railway](https://railway.app/) нажмите **New Project → Deploy from GitHub Repo** и выберите репозиторий.
3. В сервисе откройте **Variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN` — новый токен из BotFather;
   - `YANDEX_WEATHER_API_KEY` — ключ из кабинета API Яндекс Погоды.
4. Railway автоматически соберёт `Dockerfile` и запустит `node src/index.js`.
5. Откройте бота в Telegram и отправьте `/start`, затем `/now`. После этого он знает, куда отправлять ежедневные сообщения. Отправьте `/id`, скопируйте ответ и добавьте его в Railway Variables как `TELEGRAM_CHAT_ID`.

## Важно о хранении chat ID

Railway может удалить локальный файл `data/subscribers.json` при новом развёртывании. Для одного пользователя задайте `TELEGRAM_CHAT_ID` в Variables после первого `/start`: его даёт команда `/id`. Для надёжного списка нескольких пользователей подключите Railway Volume или БД.

## Локальный запуск

В PowerShell задайте значения только для текущего окна и запустите:

```powershell
$env:TELEGRAM_BOT_TOKEN = "новый-токен"
$env:YANDEX_WEATHER_API_KEY = "ключ-яндекс-погоды"
node src/index.js
```
